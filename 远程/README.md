# 远程控制（控制码连接）

一个单文件的 Windows 远程控制工具：被控电脑运行后生成**控制码**，控制端（手机 / 其他电脑）浏览器输入控制码即可查看实时屏幕并操作鼠标、键盘，默认端口 **8888**。

纯 Go 标准库实现（GDI 截屏 + SendInput 鼠键模拟），无第三方依赖，编译产物为一个 exe。

## 快速开始

### 被控电脑

```bat
remote.exe              # 默认端口 8888
remote.exe -port 9000   # 指定端口
remote.exe -code 123456 # 手动指定控制码
```

启动后控制台会打印：

- **控制码**（首次自动生成 6 位数字，之后保存在同目录 `remote-config.json`，重启不变）
- 本机访问地址 `http://localhost:8888`（在此页面可查看控制码、重新生成控制码、管理已连接设备）
- 局域网访问地址（控制端用这个）

### 控制端（手机 / 其他电脑）

1. 浏览器打开被控电脑的**真实局域网地址**，如 `http://192.168.1.3:8888`（不要用 172.x / 192.168.56.x 这类虚拟网卡地址）
2. 输入控制码 → 连接

### 操作方式

- **鼠标**：两种模式可切换
  - *触控板模式*（手机默认）：点按=左键，单指拖动=移动指针，双指滑动=滚动，「拖动」开关=按住左键拖拽，长按=右键
  - *直接触控模式*：点按=左键，按住拖动=拖拽
- **文字**：点右上角「⌨️ 文字」唤起手机系统键盘，输入后「发送」或「发送+回车」；长文本用「粘贴」秒传（写剪贴板 + Ctrl+V）
- **快捷键**：Esc / Tab / 方向键 / Ctrl+C·V·X·Z·A·S / Alt+Tab / Win+D / Win+空格 等
- **捕获键盘**：开启后控制端页面敲的按键（英文和组合键）直接发给被控电脑；中文请走文本框
- **设备管理**：被控电脑的 `localhost:8888` 页面可查看所有已连接设备并一键**踢出**

## 安全说明

- 控制码即钥匙：拿到控制码 + 能访问该端口 = 完全控制该电脑，请只在可信网络使用
- 控制码错误 5 次将封禁该 IP 15 分钟；控制码比较使用常数时间哈希
- 控制码只显示给被控电脑本机（127.0.0.1）和运行控制台，局域网访问者只能看到输入框
- 如需公网使用，建议套一层 VPN / 隧道，不要直接暴露端口

## 已知限制

- 无法操作 UAC 提示、锁屏、Ctrl+Alt+Del 等安全桌面（系统限制，普通权限程序无法注入）
- 部分独占全屏 / 硬件加速（DX 游戏）画面可能截到黑屏
- 被控端为 Windows；控制端为任意现代浏览器（Chrome / Edge / Safari / Firefox，手机可用）

## 构建

```
go build -o remote.exe .
```

要求 Go 1.22+，Windows（使用了 GDI / SendInput / 剪贴板 API）。
